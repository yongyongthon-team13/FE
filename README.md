## 한 앱, 두 가지 모드

시작 화면에서 **어르신으로 시작하기** / **보호자로 시작하기**를 고릅니다. 두 계정은 **연결 번호**로 이어집니다.

### 어르신

- **말로 하는 가입**: 이름·출생연도·사는 곳·이동 보조기구·걷기 불편 여부를 음성으로 답해요.
- **병원 일정 만들기**: 병원에서 온 문자를 붙여넣거나 캡처 사진을 올리면 AI가 날짜·시간·진료과를 뽑아요. 못 읽은 부분은 직접 입력하거나 보호자에게 부탁할 수 있어요.
- **진료과 추천**: 아픈 곳을 말하면 진료과를 추천하고, 가까운 병원을 골라 일정까지 저장해요. 위급 증상이면 119·보호자 전화로 바로 연결해요.
- **동행 서비스**: 몸 상태와 일정으로 병원 동행 서비스가 필요한지 판단하고, 전화 대본과 함께 신청을 도와요.
- **출발 알림**: 진료 시각과 경로 소요시간으로 출발 시각을 계산해 전날 저녁 / 출발 1시간 전에 알려요.
- **당일 체크**: 날씨 특보와 컨디션을 확인해 차가 필요하면 택시·보호자·특별교통수단을 추천해요. 보호자에게 부탁하면 답을 앱에서 기다려요.
- **저상버스 길 안내**: 정류장까지 걷기 → 버스 기다리기 → 타는 중 → 내리기 → 병원 도착 → 창구에 보여줄 화면까지 단계별로 안내해요. 계단 있는 버스를 보내면 다음 저상버스를, 길을 잃으면 현재 위치에서 다시 찾아줘요.

### 보호자

- **보호자 홈**: 다음 진료 D-day, 다가오는 일정, '확인이 필요해요'(문자 정보 부족·진료 후기·차량 부탁)를 한눈에 봐요.
- **이동 현황**: 진료 당일 어르신이 지금 어디쯤인지(출발·탑승·하차·도착), 도착 예상 시각, 지도 위 위치를 30초마다 갱신해요.
- **도움 주기**: 어르신이 못 읽은 일정 정보를 대신 채우고, 차량 부탁에 '모시러 갈게요 / 택시 불러드릴게요'로 답해요.
- **진료 후기**: 이동 방법·도착 시간·추천 경로가 어땠는지 남겨 다음 추천에 반영해요.
- **알림**: 이동이 늦어지거나 어르신이 응답하지 않으면 푸시로 알려요.

## 실행 방법

```bash
npm install
npx expo start          # Expo Go 또는 웹에서 실행
npx expo start -c       # 화면이 이상하면 캐시 지우고 실행
```

APK 빌드

```bash
npx eas-cli login
npx eas-cli build -p android --profile preview
```

> 음성 인식, 푸시 알림은 Expo Go에서 동작하지 않아요. APK로 확인해 주세요.

## 폴더 구조

```
src/
├── app/              # 화면 (expo-router, 파일 이름 = 주소)
│   ├── onboarding/   # 어르신 가입·일정 등록
│   ├── guardian-*    # 보호자 화면
│   └── ...           # 어르신 화면 (병원 가기, 길 안내 등)
├── api/              # 서버 연동 (화면에서 쓰는 형태로 변환)
├── components/       # 공통 컴포넌트
│   ├── guardian/     # 보호자 화면 컴포넌트 (지도 포함)
│   └── guide/        # 길 안내 단계 화면
├── hooks/            # useGuideSession(길 안내), useSpeechToText(음성)
├── lib/              # API 요청·토큰 저장·알림·푸시·전화
├── store/            # 앱 안에서 공유하는 상태
├── constants/        # 색상·글꼴 등 테마
└── assets/           # 아이콘·마스코트 SVG, 폰트
```
