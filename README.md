## 🚀 배포

| 구분 | 링크 | 비고 |
|---|---|---|
| 웹 | https://yongyongthon-team13.expo.app | 브라우저로 바로 확인 |
| 안드로이드 APK | [다운로드](APK_링크_붙여넣기) | 하차벨 진동·전화·출발 알림까지 동작 |

> 웹은 PC에서 보면 화면이 가로로 늘어나요. 크롬 개발자도구(F12) → 기기 모드(Ctrl+Shift+M)로 폰 크기로 보는 걸 추천해요.

### 둘러보는 방법
- **어르신**: 첫 화면 → `어르신으로 시작하기` → 이름·전화번호 → 인증번호 6자리 입력
- **보호자**: 첫 화면 → `보호자로 시작하기` → 연결 번호 6자리 입력 → 보호자 홈

### 테스트 안내
- 현재 서버 연동 전이라 **모든 데이터는 예시(목업)** 로 동작합니다
- 인증번호·연결 번호는 **아무 6자리 숫자**나 입력하면 통과합니다 (`000000`은 실패 테스트용)
- 웹에서는 진동·출발 알림이 동작하지 않스니다. APK로 설치해서 확인해 주세요.
